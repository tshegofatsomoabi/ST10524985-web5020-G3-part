Proposal 2: Hope Haven Animal Rescue — APPROVED

Hope Haven Animal Rescue is a proposed non-profit organisation focused on rescuing abandoned, neglected and vulnerable animals. The organisation provides temporary shelter, basic care, rehabilitation support and responsible rehoming. The proposed website would act as an accessible online hub where members of the public can learn about the organisation, enquire about adoption or fostering, volunteer, donate and report animals that may need help.

The target audience includes potential adopters, foster families, volunteers, donors, community members and organisations interested in animal welfare. The primary goals are to increase awareness, make rescue-related information easy to find, encourage responsible adoption and provide clear ways for the public to support the organisation.

The website would contain at least five pages: Home, About Us, Services, Enquiry and Contact. The Home page would introduce Hope Haven and provide strong calls to action. The About page would explain the organisation's story, mission, vision and target audiences. The Services page would describe rescue, temporary shelter, veterinary support, adoption, fostering and education. The Enquiry page would provide a form for adoption, foster, volunteer, donation and rescue enquiries. The Contact page would provide contact information and guidance for reporting an animal in danger.

The design would use a warm cream background, muted green accents and terracotta call-to-action elements to communicate care, trust and warmth. Typography would be simple and readable. The layout would be responsive and use clear navigation so users can reach important information quickly.

The technical implementation would use HTML5, CSS3 and JavaScript. The project would be organised into separate folders for CSS, JavaScript and images. Original SVG illustrations would be used for the prototype. Testing would be performed in different browsers and on different screen sizes. Website success could be measured through enquiry submissions, adoption/foster enquiries, volunteer interest, donation interest and engagement with key pages.

Hope Haven Animal Rescue is the selected and approved organisation and will therefore be used for the remainder of the project.

2. Research and Planning
2.1 Organisation Overview

Name: Hope Haven Animal Rescue
Type: Fictional non-profit animal rescue organisation
Location: Gauteng, South Africa

Focus: Rescue, temporary care, rehabilitation support, adoption, fostering, volunteering and animal-welfare education.
Background: Hope Haven was created as a fictional community rescue concept for this project. It responds to the need for a clear digital platform where the public can find rescue information and practical ways to help vulnerable animals.
Mission: To rescue abandoned and vulnerable animals, provide compassionate temporary care and connect suitable animals with safe, responsible homes.
Vision: A community where animals are treated with care, abandonment is reduced, and every suitable rescue has a genuine chance at a safe future.
Target audience: potential adopters, foster families, volunteers, donors, community members and welfare partners.

2.2 Website Goals and Objectives

Increase awareness of Hope Haven and its animal-rescue purpose.
Make adoption, fostering and volunteering information easy to find.
Provide a clear enquiry pathway for the public.
Explain rescue services and responsible animal care.
Encourage donations and community support.
Create a professional, accessible and responsive online presence.

KPIs: number of enquiry submissions, adoption enquiries, foster enquiries, volunteer enquiries, donation enquiries, page visits and engagement with the Services and Enquiry pages.

2.3 Current Website Analysis

Hope Haven is a fictional organisation created for this assignment, so it does not have an existing website to audit. Instead, the proposed site starts from a clean structure designed around the needs of an animal-rescue organisation. This avoids claiming that a fictional organisation has an existing digital presence.

2.4 Proposed Website Features and Functionality

Homepage with hero message and clear calls to action.
About page with story, mission, vision and target audiences.
Services page covering rescue, shelter, veterinary support, adoption, fostering and education.
Enquiry form for adoption, fostering, volunteering, rescue reports and donations.
Contact page with email, telephone, location and rescue-report guidance.
Responsive navigation and internal links across all pages.

Hope Haven Animal Rescue – Part 2


Part 2 Overview


Part 2 focuses on improving the visual design and responsiveness of the Hope Haven Animal Rescue website using CSS.


The original Part 1 HTML pages were kept and updated. 


What Was Added in Part 2


1. External CSS stylesheet

A new external stylesheet called style.css was created in the css folder and linked to all five HTML pages:

index.html

about.html

services.html

enquiry.html

contact.html

Using one external stylesheet keeps the design consistent across the website.


2. Base styling

A consistent base style was created for the website. This includes:

Font family and font sizes.

A consistent green, sage, cream and coral colour scheme.

Margins and padding.

A CSS reset for consistent styling across browsers.

Reusable CSS variables for colours and common design values.


3. Layout structure

CSS Grid and Flexbox were used to structure the website.

The layout includes:

Header and navigation.

Hero section.

Information cards.

Service cards.

Two-column content sections.

Enquiry form.

Contact information cards.

Footer.


4. Visual styling

CSS properties were used to improve the appearance of the website, including:

color

background-color

border

border-radius

box-shadow

Typography.

Spacing.

Buttons.

Navigation links.

Content cards.

5. Interactive styling

CSS pseudo-classes were used to improve interaction:

:hover for links and buttons.

:focus-visible for keyboard accessibility.

:active for buttons.

Focus styling for form controls.


6. Responsive design

Media queries were added to support different screen sizes:

Desktop.

Tablet.

Mobile.

The multi-column layouts change to simpler layouts on smaller screens. Navigation, text, cards, forms and spacing are also adjusted for smaller devices.


7. Relative units

Relative units such as rem, em, %, vw and clamp() were used where appropriate. Flexible grid columns and responsive widths were also used to allow the website to adapt to different screen sizes.


8. Responsive images

Responsive image techniques were added using:

picture

srcset

sizes

These allow the browser to use an appropriate image source depending on the screen size.


9. HTML comments

Explanatory comments were added to the HTML pages to describe important sections of the code.

Comments were added around areas such as:

Header and navigation.

Hero sections.

Content sections.

Forms.

Responsive images.

Footers.


10. Enquiry form improvements

The enquiry form was improved with:

Labels connected to form controls.

Required fields.

Email input validation.

An enquiry type selection.

A message field.

Improved accessibility and usability.
